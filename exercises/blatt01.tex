\textbf{Lernziele:} Eine Python-Arbeitsumgebung einrichten, kleine Programme entwickeln,
Algorithmen nachvollziehen und Klassen sowie Polymorphie einsetzen.

\textbf{Arbeitsweise:} Aufgaben 1--6 bilden den Einstieg; 7--10 dienen der anschließenden
Vertiefung und dem Selbstlernen. Planen Sie insgesamt etwa 6--8 Stunden ein, abhängig
von Vorkenntnissen und Installationen. Das Begleitnotebook \texttt{Python\_Intro.ipynb}
(Abschnitte A--D und G) hilft bei der Bearbeitung. Insgesamt: \textbf{100 Übungspunkte}.
Schreiben Sie eigene Lösungen und erläutern Sie verwendete Hilfen kurz.

\aufgabetitel{12}{Python und VS Code einrichten}\\
\begin{enumerate}[a)]
\item Installieren Sie Python 3.12 oder neuer, VS Code sowie die Microsoft-Erweiterungen
\emph{Python} und \emph{Jupyter}. Prüfen Sie im Terminal die Python-Version:
\texttt{python3 --version} (macOS/Linux) bzw. \texttt{py -3 --version} (Windows).
\item Öffnen Sie einen neuen Projektordner \texttt{python-intro} in VS Code.
Erstellen Sie über \emph{Python: Create Environment} eine virtuelle Umgebung
\texttt{.venv} und wählen Sie sie über \emph{Python: Select Interpreter} aus.
\item Erstellen Sie \texttt{hello.py}, das Ihren Namen und \texttt{Hallo Python!} ausgibt.
Führen Sie die Datei aus. Geben Sie zusätzlich mit \texttt{sys.version} und
\texttt{sys.executable} Version und Pfad des verwendeten Interpreters aus.
\item Setzen Sie einen Breakpoint vor einer Ausgabe und starten Sie den Debugger.
Ändern Sie eine Variable und beobachten Sie ihren Wert. Erklären Sie in der
\texttt{README.md} den Unterschied zwischen Editor, Interpreter und virtueller Umgebung.
\end{enumerate}
\textbf{Nachweis:} \texttt{hello.py}, dokumentierte Python-Version, Interpreterpfad und kurze Erklärung.

\aufgabetitel{8}{Git und GitHub einrichten}\\
\begin{enumerate}[a)]
\item Erstellen Sie ein GitHub-Konto, installieren Sie Git und prüfen Sie \texttt{git --version}.
Legen Sie auf GitHub ein Repository \texttt{python-intro} mit README an und klonen Sie es
über VS Code (\emph{Git: Clone}) in einen separaten Ordner. Öffnen Sie diesen als Projekt.
\item Übernehmen Sie \texttt{hello.py} und Ihre README-Inhalte. Erstellen Sie die virtuelle
Umgebung im geklonten Projekt neu. Tragen Sie \texttt{.venv/}, \texttt{\_\_pycache\_\_/}
und \texttt{.ipynb\_checkpoints/} in \texttt{.gitignore} ein.
\item Konfigurieren Sie Ihren Git-Namen und Ihre Commit-E-Mail. Erstellen Sie einen Commit
und pushen Sie ihn. Legen Sie einen Branch \texttt{begruessung} an, ändern Sie die Begrüßung und pushen Sie den Branch.
Öffnen und mergen Sie einen Pull Request; aktualisieren Sie anschließend lokal \texttt{main}.
\item Erklären Sie Git vs. GitHub sowie Commit vs. Push. Halten Sie Repository-URL und
Commit-Kennung in der README fest. Zugangsdaten gehören nicht ins Repository.
\end{enumerate}
\textbf{Hilfe:} \href{https://code.visualstudio.com/docs/python/python-tutorial}{VS Code: Python-Tutorial};
\href{https://docs.github.com/en/get-started/using-github/hello-world}{GitHub: Hello World}.

\aufgabetitel{8}{Ein Python-Programm mit Docker ausführen}\\
\begin{enumerate}[a)]
\item Installieren und starten Sie Docker Desktop gemäß der
\href{https://docs.docker.com/get-started/get-docker/}{offiziellen Anleitung}
(unter Linux alternativ Docker Engine). Prüfen Sie im lokalen Terminal:
\begin{lstlisting}[language={}]
docker --version
docker run --rm hello-world
\end{lstlisting}
\item Erstellen Sie neben \texttt{hello.py} eine Datei \texttt{Dockerfile} mit folgendem Inhalt.
Für dieses Programm sind keine zusätzlichen Python-Pakete erforderlich.
\begin{lstlisting}[language={}]
FROM python:3.12-slim
WORKDIR /app
COPY hello.py .
CMD ["python", "hello.py"]
\end{lstlisting}
\item Bauen und starten Sie das Image im Projektordner:
\begin{lstlisting}[language={}]
docker build -t python-intro .
docker run --rm python-intro
\end{lstlisting}
Vergleichen Sie die Ausgabe mit der lokalen Ausführung. Ändern Sie die Begrüßung in
\texttt{hello.py}. Was wird ohne erneuten Build ausgegeben, was nach einem neuen Build?
\item Erklären Sie die Begriffe Dockerfile, Image und Container sowie den Unterschied
zwischen einem Container und einer Python-Umgebung \texttt{.venv}.
\end{enumerate}
\textbf{Nachweis:} Dockerfile, Befehle und beobachtete Ausgaben in der README.
Falls die Installation auf Ihrem Gerät scheitert, dokumentieren Sie Fehlermeldung und
Lösungsversuch; bearbeiten Sie die Python-Aufgaben zunächst in Colab weiter.

\aufgabetitel{12}{Kleine Programme: Variablen, Bedingungen und Schleifen}\\
\begin{enumerate}[a)]
\item \textbf{Temperaturumrechner (3 P.):} Lesen Sie eine Celsius-Temperatur mit \texttt{input}
ein, wandeln Sie sie mit \texttt{float} in eine Zahl um und berechnen Sie
$F=C\cdot 9/5+32$. Geben Sie das Ergebnis mit einer Nachkommastelle aus.
Prüfen Sie $0\mapsto32$, $100\mapsto212$ und $-40\mapsto-40$.
Warum ist eine Typumwandlung nötig?
\item \textbf{Versandkosten (3 P.):} Schreiben Sie \texttt{versand(warenwert)}.
Für einen nichtnegativen Warenwert unter 50 Euro betragen die Versandkosten 4{,}90 Euro,
ab 50 Euro sind sie null. Negative Werte sollen einen \texttt{ValueError} auslösen.
Prüfen Sie 0, 49{,}99, 50 und $-1$.
\item \textbf{FizzBuzz (3 P.):} Geben Sie die Zahlen 1 bis einschließlich 30 aus.
Ersetzen Sie durch 3 teilbare Zahlen durch \texttt{Fizz}, durch 5 teilbare durch
\texttt{Buzz} und durch beide teilbare durch \texttt{FizzBuzz}.
Nutzen Sie \texttt{\%}. Warum ist die Reihenfolge der Bedingungen wichtig?
\item \textbf{Umsätze (3 P.):} Gegeben sind \texttt{preise = [12, 8, 15, 10]} und
\texttt{mengen = [2, 5, 1, 3]}. Berechnen Sie mit einer Schleife die Einzelumsätze,
den Gesamtumsatz und die Anzahl der Einzelumsätze ab 30 Euro.
Erwartung: \texttt{[24, 40, 15, 30]}, Gesamtumsatz 109, Anzahl 2.
\end{enumerate}

\aufgabetitel{10}{Funktionen, Strings und Dictionaries}\\
\begin{enumerate}[a)]
\item \textbf{Durchschnitt (4 P.):} Implementieren Sie \texttt{durchschnitt(werte)} für eine
Liste von Zahlen ohne \texttt{sum}. Bei einer leeren Liste soll \texttt{ValueError}
ausgelöst werden. Prüfen Sie:
\begin{lstlisting}
assert durchschnitt([2, 4, 6]) == 4
assert durchschnitt([5]) == 5
assert durchschnitt([-4, 2]) == -1
\end{lstlisting}
Ergänzen Sie einen Test mit \texttt{try/except}, der den Fehlerfall überprüft.
\item \textbf{Palindrom (3 P.):} Implementieren Sie \texttt{ist\_palindrom(text)}.
Ignorieren Sie Groß-/Kleinschreibung und Leerzeichen; andere Zeichen bleiben erhalten.
\texttt{"Lagerregal"} und \texttt{"Ab ba"} liefern \texttt{True}, \texttt{"Python"}
liefert \texttt{False}. Der leere String gilt hier als Palindrom.
Tipp: \texttt{lower}, \texttt{replace} und Slicing.
\item \textbf{Häufigkeiten (3 P.):} Zählen Sie in
\texttt{["Web", "Shop", "Web", "Partner", "Web"]} die Häufigkeit jedes Werts
mit einem Dictionary und einer Schleife, ohne \texttt{Counter}.
Erwartung: \texttt{\{"Web": 3, "Shop": 1, "Partner": 1\}}.
Verpacken Sie den Code in \texttt{haeufigkeiten(werte)}; für \texttt{[]} ist das Ergebnis
\texttt{\{\}}. Tipp: \texttt{dict.get}.
\end{enumerate}
\textbf{Reflexion:} Erklären Sie an einer Ihrer Funktionen den Unterschied zwischen
\texttt{print} und \texttt{return}, zwischen Parameter und Argument sowie zwischen
\texttt{=} und \texttt{==}.
